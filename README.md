# Liberty Class and Career — Student Portal

Complete Student Portal built with the requested stack:

- HTML5
- Tailwind CSS
- Custom CSS
- Vanilla JavaScript
- PHP 8+
- MySQL / MariaDB

No React, Next.js, Node.js backend or Cloudflare database is used.

## Included features

- Same Liberty red, gold and navy branding
- Original Liberty Class and Career and Liberty Foundation logos
- Four-slide promotional hero banner
- Animated Liberty icon, rotating rings and floating labels
- Home statistics, Skill Training, Online Degree and Admission sections
- Three-course step slider every three seconds
- Institute card fade/position animation every three seconds
- Degree card animation with hover pause
- Skill Training listing and search
- Course details/pricing modal and working enrollment submission
- Online degree grid, details and syllabus modal
- Admission institute cards and multi-course selection without checkboxes
- Separate blurred Request a Call Back modal
- Contact Us modal with validation
- My Courses and CBT student screens
- Profile dropdown and logout interaction
- Responsive desktop, tablet and mobile UI
- Secure PHP PDO prepared statements
- CSRF protection and JSON APIs
- Complete MySQL schema with seed data

## cPanel / Namecheap installation

1. Extract the ZIP inside your domain's `public_html` directory.
2. In cPanel, create a MySQL database and database user.
3. Assign the user to the database with **ALL PRIVILEGES**.
4. Open phpMyAdmin, select the new database and import:

   `database/schema.sql`

5. Edit `config/config.php`:

```php
return [
    'db_host' => 'localhost',
    'db_port' => '3306',
    'db_name' => 'cpanelprefix_database',
    'db_user' => 'cpanelprefix_user',
    'db_pass' => 'your-secure-password',
];
```

6. Visit the domain in your browser.

## API endpoints

- `POST api/contact-inquiries.php`
- `POST api/enrollments.php`

## Production notes

- PHP 8.0+ with PDO MySQL must be enabled.
- MySQL 5.7+/MariaDB 10.4+ is recommended.
- The exact Tailwind v4.2.1 production stylesheet from the approved reference build is bundled locally, preventing CDN-version reset and spacing differences. Lucide icons are version-pinned from its official CDN.
- Replace the temporary app download URL in `index.php` when the Play Store link is ready.
- The Student profile is currently the same demo profile shown in the approved design. Login/payment/full CBT exam delivery can be connected when the Admin and authentication phase is added.
