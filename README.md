# Liberty Class and Career — Student Portal

## New Windows laptop or server

Install the Admin repository first. Its migration runner creates both the Skill Training catalogue and the shared CBT catalogue:

```powershell
cd lcc_admin
Copy-Item .env.example .env
php database/migrate.php --database=all
php tools/import_skill_syllabuses.php
```

The migration includes the 12 Skill Training courses and the validated CBT baseline of 33 tests, 970 questions and 3,880 options. It is idempotent, so rerunning it does not duplicate records. The original CBT DOCX ZIP does not need to be imported again.

Create the Student environment file:

```powershell
cd ..\lcc_web
Copy-Item .env.example .env
```

Configure the Admin connection and use exactly the same `SKILL_LEAD_API_TOKEN` in both projects:

```dotenv
APP_ENV=local
APP_DEBUG=false
APP_URL=http://127.0.0.1:8000

LCC_ADMIN_API_BASE_URL=http://127.0.0.1:8001/api
SKILL_LEAD_API_TOKEN=use-the-same-long-random-value-as-the-admin-project
SKILL_LEAD_WHATSAPP_NUMBER=918276015376

DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=lcc_cbt
DB_USERNAME=your_database_user
DB_PASSWORD=your_database_password
```

Start both applications in separate terminals:

```powershell
# Admin repository
php -S 127.0.0.1:8001

# Student repository
php -S 127.0.0.1:8000 router.php
```

Open:

- Student website: `http://127.0.0.1:8000/`
- Student CBT: `http://127.0.0.1:8000/cbt`
- Admin: `http://127.0.0.1:8001/lcc/`

Admin and Student must point to the same `lcc_cbt` database. Do not import CBT data into a second Student database. Admin-uploaded runtime files must be copied with protected upload storage when moving an existing live installation; built-in fallback course thumbnails are already included in this repository.

Complete Student Portal built with the requested stack:

- HTML5
- Tailwind CSS
- Custom CSS
- Vanilla JavaScript
- PHP 8+
- MySQL / MariaDB

No React, Next.js, Node.js backend or Cloudflare database is used.

## cPanel / Namecheap installation

1. Extract the ZIP inside your domain's `public_html` directory.
2. In cPanel, create a MySQL database and database user.
3. Assign the user to the database with **ALL PRIVILEGES**.
4. Open phpMyAdmin, select the new database and import:

   `database/schema.sql`

5. Edit `config/config.php`:

```php
return [
    'db_host' => 'localhost',
    'db_port' => '3306',
    'db_name' => 'cpanelprefix_database',
    'db_user' => 'cpanelprefix_user',
    'db_pass' => 'your-secure-password',
];
```

6. Visit the domain in your browser.

## Popular Skill Training integration

The Popular Skill Training cards are read from the Admin application's published
Skill Training catalogue. Set the public Admin API base URL in the Student `.env`:

```dotenv
LCC_ADMIN_API_BASE_URL=http://localhost:8001/api
SKILL_LEAD_API_TOKEN=replace-with-the-same-long-random-value-used-by-admin
SKILL_LEAD_WHATSAPP_NUMBER=918276015376
```

The Student server requests `public_skills.php` on each page load. If the Admin API
is unavailable or has no published records, the original built-in cards and
thumbnails are rendered automatically. Admin-uploaded thumbnails are delivered by
the public thumbnail endpoint; missing or failed images fall back to the matching
original Student thumbnail.

Skill enrollment interest is submitted through the Student server to the Admin API.
The Admin and Student servers must share `SKILL_LEAD_API_TOKEN`. After a lead is
stored, Student opens a prefilled WhatsApp message for the configured support number.

## API endpoints

- `POST api/contact-inquiries.php`
- `POST api/enrollments.php`

Admin application (public, read-only):

- `GET /api/public_skills.php`
- `GET /api/public_skill_thumbnail.php?id={skill_id}`

Both endpoints require the CSRF token generated by `index.php`, validate input and use PDO prepared statements.

## Production notes

- PHP 8.0+ with PDO MySQL must be enabled.
- MySQL 5.7+/MariaDB 10.4+ is recommended.
- The exact Tailwind v4.2.1 production stylesheet from the approved reference build is bundled locally, preventing CDN-version reset and spacing differences. Lucide icons are version-pinned from its official CDN.
- Replace the temporary app download URL in `index.php` when the Play Store link is ready.
- The Student profile is currently the same demo profile shown in the approved design. Login/payment/full CBT exam delivery can be connected when the Admin and authentication phase is added.
